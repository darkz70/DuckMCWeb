# DuckMC Web

Сайт лаунчера DuckMC: скачивание, новости обновлений Minecraft (Java-релизы, снимки, Бедрок) и поддержка разработчика.

## Структура

- `index.html` — главная страница с загрузкой лаунчера
- `news.html` — новости обновлений Minecraft (загружаются из `data/news.json`)
- `donate.html` — страница поддержки со ссылкой на [Buy Me a Coffee](https://buymeacoffee.com/darkz69i42k)
- `css/style.css` — стили
- `js/app.js` — общий скрипт (мобильное меню)
- `js/news.js` — рендер новостей
- `data/news.json` — данные новостей
- `vercel.json` — конфиг для Vercel
- `assets/logo.svg` — логотип DuckMC (заглушка, замените на свою иконку)

## Деплой на Vercel

1. ЗаPush'ите этот репозиторий на GitHub.
2. Зайдите на [vercel.com](https://vercel.com) и импортируйте репозиторий.
3. Настройка не требуется — Vercel определит статический сайт автоматически.
4. Готово: сайт будет доступен по адресу `https://duckmcweb.vercel.app` (или ваш домен).

Ссылка на донаты ведёт на `https://buymeacoffee.com/darkz69i42k`.

> ⚠️ Ссылки скачивания лаунчера пока заглушки ("Скоро будет"). Замените `#` в `index.html` на реальные ссылки к файлам лаунчера, когда они будут готовы.
